## Cross-cutting acceptance requirements

- Every tenant-owned record has a non-null tenant identifier and tenant-aware foreign keys where supported.
- Every request is authenticated and authorized on the server. Hiding a link is not access control.
- Client and subcontractor access is limited to explicit project assignments and published/assigned data.
- Mutations validate input, run in a transaction when multiple records change, and produce traceable audit events for consequential operations.
- Money, units, timezone, dates and tax are explicit; financial documents retain a snapshot of applied rules.
- File access requires authorization before a short-lived URL is created.
- List/search/export paths apply the same authorization filters as detail routes.
- Integration callbacks are signature-checked, idempotent and safe to replay.
